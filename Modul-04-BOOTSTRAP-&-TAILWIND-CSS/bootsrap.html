Pendaftaran Praktikum Pemrograman Web

Informasi Praktikum

Praktikum Pemrograman Web merupakan kegiatan pembelajaran yang bertujuan untuk memberikan pemahaman dan pengalaman kepada mahasiswa dalam membuat serta mengembangkan halaman web menggunakan teknologi HTML, CSS, dan framework web.

Melalui praktikum ini, peserta akan mempelajari dasar-dasar pembuatan website, struktur halaman HTML, penggunaan CSS, serta penerapan framework Bootstrap dalam membangun halaman web yang responsif.
